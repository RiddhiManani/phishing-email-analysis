# Phishing Email Analysis

## Objective

Analyze a suspicious email sample and identify phishing characteristics such as spoofed sender information, suspicious headers, social engineering techniques, and spam indicators.

## Files Included

* phishing_sample.txt
* Phishing_Email_Analysis_Report.pdf

## Analysis Performed

* Sender Email Analysis
* Reply-To Analysis
* Header Analysis
* Spam Score Review
* SPF Verification
* Social Engineering Detection
* Grammar and Language Analysis

## Findings

The email exhibited multiple phishing indicators including:

* Sender and Reply-To mismatch
* High spam score
* Spam classification by mail server
* Financial scam content
* Social engineering techniques
* Grammar inconsistencies

## Conclusion

The analyzed email was determined to be a phishing/scam email based on the identified indicators.
